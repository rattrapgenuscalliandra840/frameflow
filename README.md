## 🛠 Features

Frameflow focuses on local processing to keep your design files fast and private. The interface allows for precise control over every element in your screenshot sets.

### AI Integration
You can connect your own API keys to the software. This allows you to generate text and descriptions for your store assets automatically. Because you provide the key, you maintain full control over the AI usage and billing.

### Layer-Based Editing
The canvas allows you to stack elements like text, device frames, and backgrounds. You can hide, show, or resize these layers at any time. This creates a non-destructive workflow where you can experiment with designs without losing your original assets.

### Export Tools
Once your design looks correct, the export tool generates files that meet the strict requirements of the Apple App Store. You receive ready-to-upload images.

## 🔍 Frequently Asked Questions

**Where are my files stored?**
All project files stay on your computer. The software does not send your designs to a cloud server.

**Can I use my own fonts?**
Yes, the application detects any system fonts installed on your computer. If you install a new font in Windows, it will appear in the Frameflow font menu upon the next restart.

**Does this require a constant internet connection?**
No. You only need the internet to download the app or if you use an external AI provider. The canvas editor works entirely offline.

**My antivirus blocks the app.**
This happens sometimes with software downloaded from GitHub. The software is safe. You can set an exception in your security settings to allow the application to run.

**How do I update the software?**
To get the latest version, visit the download link again. Download the new installer and run it over the old one. Your settings and designs will remain intact.

## 🚀 Troubleshooting

If the software fails to open:
- Ensure you have the latest version of Windows installed.
- Close other demanding applications that might use large amounts of memory.
- Check if your firewall is preventing the app from launching.

If the AI features do not work:
- Check your connection to the internet.
- Verify that you entered your API key correctly in the settings menu.
- Ensure your API key has sufficient usage credits.
